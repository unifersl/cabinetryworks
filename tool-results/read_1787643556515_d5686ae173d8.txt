     1→# Worklog — Custom Kitchen & Cabinetry Manufacturing System
     2→
     3→## Project Overview
     4→Full-stack web app for a Custom Kitchen & Cabinetry Manufacturing Business.
     5→- **Stack**: Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + shadcn/ui + Prisma (SQLite) + lucide-react
     6→- **Note on Supabase**: The user requested Supabase. This environment uses **Prisma + SQLite**.
     7→  The robust user-creation pattern (frontend UUID → primary handler → mandatory fallback → toast + refetch)
     8→  is preserved by mapping it onto Prisma-backed API routes (`/api/users` primary create,
     9→  `/api/users/direct` fallback insert). RBAC, Error Boundaries, explicit icon imports, and
    10→  `DialogTitle` accessibility safeguards are all implemented as specified.
    11→
    12→## Roles (RBAC)
    13→- **Admin / Super Admin**: Full access — User Management, Job Orders, Site Measurements, Factory Cutting Lists, System Settings.
    14→- **Technician**: Simplified mobile/tablet view — Site Measurement, Photo Markup, Elevation Blueprinting, Cutting List entry.
